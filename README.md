# Shadow Link Updates

Публичный канал сведений о новых версиях Shadow Link. Репозиторий не содержит исходный код приложения, сертификаты, UDID, токены или другие приватные данные.

## Публикация релиза

`ios.json` обновляет production-портал IPA Vault. После загрузки и проверки IPA
администратор заполняет «Что нового» и нажимает «Выпустить» в карточке Shadow
Link. Портал формирует manifest из фактически опубликованной версии и записывает
его отдельным repository-scoped deploy key. Только после успешной записи GitHub
версия фиксируется в публичном каталоге.

Вручную редактировать `ios.json` при обычной публикации не нужно. Ссылка из
manifest открывает карточку Shadow Link на портале: IPA подписывается
персональным сертификатом пользователя и не хранится здесь.

Для немедленного отключения баннера установить `enabled: false`. Принудительных обновлений нет: VPN продолжает работать независимо от доступности этого файла.

## Контракт v1

- `schema_version`: `1`;
- `enabled`: `true` или `false`;
- `version`: отображаемая версия;
- `build`: положительный числовой `CFBundleVersion`;
- `title`: заголовок релиза;
- `changelog`: от 1 до 20 непустых строк;
- `download_url`: разрешённая HTTPS-ссылка портала или `null`;
- `published_at`: ISO 8601 или отсутствие поля.
